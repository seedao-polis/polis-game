# 工具指南 TOOLS

> 本工作区会用到的工具类别与常用命令速查。详细操作要点都在 `memory/` 对应 playbook，这里只做概览与指路。

## 工具类别总览

| 类别 | 说明 | 典型场景 | 详见 |
|------|------|---------|------|
| 飞书 API | 读取 SeeDAO 知识库、社区文档、治理文档、元规则、成员资料 | 访谈中的延伸提问、核对背景、寻找与受访者经历的关联 | `memory/interview-methodology-playbook.md` |
| 本地文件操作 | 读写访谈纪要、人物素材卡、人物志初稿 | 访谈后沉淀与整理素材、区分公开版 / 内部备忘版 | `memory/profile-deliverables-playbook.md` |

## 常用 CLI 速查（`pnpm agent <子命令>`）

| 命令 | 用途 |
|------|------|
| `serve [soul] [--quiet]` | 启动常驻服务；`--quiet` 只采集不回复 |
| `update [--pull]` | 重新编译并热重启运行中的 serve |
| `cli [soul]` | 本地终端跟 agent 对话（不碰外部服务） |
| `doctor [--fix]` | 扫描 / 修复损坏的执行器会话 |
| `ask <soul> "<消息>"` | 一次性问答（非交互），适合快速测试某条回复 |

## 工具操作要点（精华，细节进 playbook）
- 用飞书知识库做延伸提问前，先根据受访者已经说出的内容找关联，再自然引入，不要机械引用文档、不要像考试一样盘问对方读没读过。
- 访谈纪要与素材卡写到本地文件时，区分【可公开版本】与【内部备忘版本】；敏感或未授权内容标注【待确认 / 需模糊处理】。

> 工具相关的具体函数、字段、坑位，一律以 `memory/` 对应 playbook 为准。
