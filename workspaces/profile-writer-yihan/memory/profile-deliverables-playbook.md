# 人物志产出 playbook

> 一涵在访谈后整理素材、写人物志初稿的产出清单与格式规范。

## 一、产出清单

访谈前后可以输出：

1. 访谈提纲
2. 访谈追问清单
3. 访谈纪要
4. 人物素材卡
5. 人物关键词
6. 人物故事线
7. 可公开版本与内部备忘版本
8. 人物志初稿
9. 标题候选
10. 金句摘录
11. 待确认问题清单
12. 需要受访者授权或模糊处理的内容列表

## 二、人物素材卡格式

整理素材时使用如下结构：

- 受访者姓名／昵称：
- 基本身份：
- 当前状态：
- 成长背景：
- 重要人生节点：
- 关键转折：
- 核心价值观：
- 代表性故事 / 场景（含细节：何时何地、还有谁、做了什么、感受、之后变化）：
- 物件锚点（让人物活起来的具体物件 / 习惯）：
- 矛盾与张力：
- 入行 / 入圈故事（常是"起初不看好 → 某个信任契机"）：
- 别人对他的评价（交叉印证）：
- 独特性 / 习惯：
- 与 SeeDAO / 社群的关系（一条支线、点到为止）：
- 可延伸访谈问题：
- 可引用金句：
- 需要模糊处理或确认的内容：
- 初步人物标签：
- 可能的人物志主题：

## 三、人物志初稿写作要求

风格：

- 不写成简历
- 不写成官方宣传稿
- 不过度拔高人物
- 不使用空泛形容词堆砌
- 优先使用具体故事、场景、语言和选择来呈现人物
- 允许保留人物的矛盾、犹豫、探索与未完成感
- 用温柔但清晰的叙事语气
- **大量直引受访者原话**（带引号），尤其金句与情绪化表达；抽象判断后紧跟一个比喻引语；适当引用身边人对他的评价做交叉印证
- **开头用场景切片或金句起手、结尾留开放余韵并与开头意象呼应**；篇幅以 2000–3500 字的散文体为宜，不做成 5000+ 字逐字实录
- 让读者读完后理解：**这个人是谁、他如何成为现在的自己**；他与 SeeDAO / 社群的关系只是其中一条线，点到为止

建议文章结构（以人为主的弧线，据 `../examples/` 范文 Grace / kc 反推）：

1. **开头切片**：一个场景或一句金句（必备，绝不从履历起手）。
2. **来路**：成长背景与人生路径（可用 2–3 个小标题切人生段落）。
3. **转折**：关键选择 / 挫折 / 契机。
4. **当下在做的事**：此刻的重心；SeeDAO 若自然相关，**在这里作为"其中一条线"轻轻带过，不单独成章**。
5. **内在驱动 / 矛盾张力**：价值观，以及他身上的拉扯（如 Grace 的 builder/trader 自成一节）。
6. **结尾**：一个仍在展开的画面、愿望或开放问题，尽量与开头意象呼应。

> 注：原先"加入 SeeDAO 契机 / 对数字城邦想象 / 在社区可能行动"三段已合并、降权为"当下"段里的可选支线，不再是必备独立章节——以守住"以人为主、SeeDAO 浅触"。

## 四、公开与授权

- 产出区分【可公开版本】与【内部备忘版本】。
- 涉及隐私、情绪、未授权的内容，标注【待确认 / 需模糊处理】，对外公开前先与受访者及操作者确认。
