# 人物志产出 playbook

> 一涵在访谈后整理素材、写人物志初稿的产出清单与格式规范。

## 一、产出清单

访谈前后可以输出：

1. 访谈提纲
2. 访谈追问清单
3. 访谈纪要
4. 人物素材卡
5. 人物关键词
6. 人物故事线
7. 可公开版本与内部备忘版本
8. 人物志初稿
9. 标题候选
10. 金句摘录
11. 待确认问题清单
12. 需要受访者授权或模糊处理的内容列表

## 二、人物素材卡格式

整理素材时使用如下结构：

- 受访者姓名／昵称：
- 基本身份：
- 当前状态：
- 成长背景：
- 重要人生节点：
- 关键转折：
- 核心价值观：
- 代表性故事：
- 加入 SeeDAO 的契机：
- 对 SeeDAO 数字城邦的理解：
- 关注的社区议题：
- 想在社区中做的事：
- 可延伸访谈问题：
- 可引用金句：
- 需要模糊处理或确认的内容：
- 初步人物标签：
- 可能的人物志主题：

## 三、人物志初稿写作要求

风格：

- 不写成简历
- 不写成官方宣传稿
- 不过度拔高人物
- 不使用空泛形容词堆砌
- 优先使用具体故事、场景、语言和选择来呈现人物
- 允许保留人物的矛盾、犹豫、探索与未完成感
- 用温柔但清晰的叙事语气
- 让读者读完后理解：这个人是谁，他为什么来到 SeeDAO，他想在这座数字城邦里寻找或建造什么

建议文章结构：

1. 开头场景或人物切片
2. 成长背景与人生路径
3. 重要转折或核心关切
4. 加入 SeeDAO 的契机
5. 对数字城邦的想象
6. 在社区中的可能行动
7. 结尾：一个仍在展开的问题、愿望或画面

## 四、公开与授权

- 产出区分【可公开版本】与【内部备忘版本】。
- 涉及隐私、情绪、未授权的内容，标注【待确认 / 需模糊处理】，对外公开前先与受访者及操作者确认。
