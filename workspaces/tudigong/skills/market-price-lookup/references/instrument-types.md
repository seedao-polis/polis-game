# 标的类型与 secid

East Money（东方财富）用 `secid = <市场前缀>.<代码>` 定位任何一个标的。本 skill 覆盖东财能查到的**所有**类型：A股、港股、美股、ETF、基金、指数、板块/概念、债券、期货、外汇等。

## 核心做法：优先用 resolve，别手拼 secid

拿到一个名字或代码，**先跑 `resolve`** 让搜索接口回候选（每条带 `secid`=QuoteID、`name`、`type`）：

```
node scripts/fetch.mjs resolve 贵州茅台
```

拿到候选后，挑对的那条的 `secid` 去 `quote` / `kline`。这样对任何市场都通用，不用记市场前缀。

**为什么不建议手拼**：同一个代码/名字在不同市场会撞车。例如 `KS11` 搜出来第一条是债券 `155.KS11`、第二条才是指数 `100.KS11`；`00700` 会同时命中港股腾讯、深A、韩股。所以 `quote`/`kline` 传裸名字时脚本只取第一条，可能选错——回传里带 `resolved`（实际用的那条）和 `alternatives`（其他候选），**务必核对 `resolved.name` 是不是你要的**，不对就改传确切 `secid`。

## 观察到的市场前缀（仅供参考，不是官方全集）

| 前缀 | 市场 | 例 |
|------|------|----|
| `1` | 沪A / 上海 | `1.600519` 贵州茅台 |
| `0` | 深A / 深圳（含创业板 300、指数 399） | `0.399001` 深证成指 |
| `116` | 港股 | `116.00700` 腾讯控股 |
| `105` / `106` / `107` | 美股（NASDAQ / NYSE / AMEX 等） | `105.AAPL` 苹果 |
| `100` | 国际指数 | `100.KS11` 韩国KOSPI |
| `90` | 板块 / 概念 | `90.BK1617` 黄金板块 |
| `155` | 债券（部分） | `155.KS11` |
| `177` | 韩股 | `177.000700` |

前缀不用背，`resolve` 会直接给你完整 `secid`。

## 已知查不到（诚实边界，别硬查、别拿相近标的冒充）

- **KRX 半导体指数 / KRXSEM**：East Money（含 resolve 搜索）、yfinance、FinanceDatabase **全都不收录**。`resolve 韩国半导体` 实测回空。**遇到「韩国半导体指数」的提问，只能降级答 KOSPI（`100.KS11`）大盘，或引导用户去 Investing.com（`cn.investing.com/indices/krx-semiconductor`），绝不拿 KOSDAQ 半导体等相近标的冒充、绝不臆测数字。**
- **韩国KOSDAQ、费城半导体 SOX**：直接手拼 `100.KOSDAQ` / `100.SOX` 无数据；如需要，先 `resolve` 看有没有别的可用代码，没有就如实告知。
