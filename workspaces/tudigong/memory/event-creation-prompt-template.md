# 新事件创建 Prompt 模板

> 把下面这份填好发给我（城邦土地神的开发对话），我就能把事件正确建好。
> 不用懂代码：群名、人名直接写中文名即可，我来解析成 chat_id / open_id；图给我链接或路径，我来下载。
> 不确定的字段写【不确定】或留空也行，我会按默认值处理或回头问你。

---

## 一、基本信息（必填）

- **事件名（中文标题）**：例如【社区潜水被发现了】。可带 emoji；**也可带占位符**（如 `🐟 '{{lurker_name}}' 在社区潜水被发现了`，名字由动态挑选填入）。
- **事件用途/一句话说明**：这事件想达到什么效果、什么时候该发生。
- **事件英文 id（可选）**：kebab-case，如 `lurker-discovered`；不填我帮你起。

## 二、文案内容（必填）

- **正文**：直接写最终文案。需要变量的地方用占位符：
  - 时间类：`{{date}}`(2026-06-17) `{{date_cn}}`(2026年06月17日) `{{time}}`(14:30) `{{weekday_cn}}`(周三)
  - 人物类（针对某个对象时）：`{{name}}` `{{ap}}` `{{level}}` `{{badges}}`
  - **@某人**：写 `{{@xxx}}`，并在下面【四、@与对象】说明 xxx 是谁。
- **有没有【按条件才出现的句子】**：例如【他若曾互动过就加：也给他 3 AP】。把条件和那句话列清楚。
- **末尾固定说明句**（可选）：如【此事件固定每周发生一次，发生概率 25%】。

## 三、配图（必填其一）

- **底图**：给我**图片链接**（我会下载存到 `workspaces/tudigong/assets/events/<id>/base.png`，全分辨率）或现有路径。
- 发送时**自动等比缩放到 128px 高**（`EVENT_IMAGE_HEIGHT`，小图缩略图风格；需要别的高度就说，按事件设 `imageHeight`）。原图留底，发送小图自动生成，不用手动准备两份。
- **图上要不要叠字**（可选）：要的话说明叠什么字、大概位置（左/中/右、上/中/下）、颜色。不要就不叠。

## 四、事件来源（必填）— 这事件从哪里【看出来】要发生

- **来源群**：从哪些群的数据判断（一个或多个群名，或【全部监听群】）。
- **DB 状态**（可选）：依赖哪些数据库状态/阈值，例如【某人 AP 破 10000】【某人升到 N 级】【某人 N 天没发言】。
- 说明：来源 ≠ 目标。来源是【素材/触发依据】（群消息 + DB），目标是【发给谁】。

## 五、通知目标（必填）— 发给谁，**只有一个**

- **二选一**：
  - 发到**一个群**：写群名（如 SeeDAO 运营小天地）。
  - 发**一个人的私聊 P2P**：写人名（如 操作者 内部）。
- 说明：一次只发一个目标。**被 @/恭喜的对象不一定在目标会话里也没关系**——若对象不在目标会话，`@` 会自动降级成【@名字】纯文本照常发出（飞书不允许 `at` 非会话成员，但文本提及可以）。个人类事件（恭喜升级 / AP 破万）通常目标 = 那个人的 P2P。
- ⚠️ 若目标是**群**：发送身份是 bot，**bot 必须已在该群里**才能发（否则报 230002）；目标是 P2P 则 bot 天然在里面，无此问题。

## 六、@ 与【对象】是谁（针对性事件才填）

- **@/主角是谁**：
  - 固定某人（写人名），或
  - **动态挑选**：从【第四节的来源群】成员里挑，按什么规则？例如：
    - 范围：**来源群的成员**（默认就是它，不是全部监听群）/ 只其中发过言的人 / 满足某 DB 阈值的人（升级、AP 破万…）/ …
    - 条件：最近 N 天没发言 / 从没发言 / 新加入 / 刚升级 / AP 刚破某值 / …
    - 随机一个 还是 最符合的一个？
- **要排除谁**：默认**只排除 bot 自己**（操作者和任何人都可被选中）。如需额外排除谁再说明。
- **挑不到人时怎么办**：不发送 / 还是强制挑一个演示？（手动 `pnpm agent event` 默认强制挑一个）

## 七、触发方式（必填）

- **只手动触发**（`pnpm agent event <编号|id>`）：写【手动】。
- **定时+随机**：选一种周期，并给概率（和时段）：
  - 每 N 分钟（无时段）/ 每 X 天 / 每周礼拜几（**1=周一 … 7=周日**）/ 每月第几号 / 每年某月某日（后四种 +时段）
  - **时段**：本地 `HH:MM-HH:MM`，到新的一天会在时段内随机挑个时间触发（【一天】按 **05:00→次日04:59** 算）。
  - **概率**：如 25%（到点掷骰，命中才发）。
- **DB 状态触发**（个人 P2P 类，如恭喜升级 / AP 破万）：写明【当某人 <某状态变化> 时，P2P 给他发】。例如【AP 首次 ≥ 10000】【level 升到 N】。（这类触发框架我会按需补；目标通常是那个人的 P2P。）
- 说明：手动触发**不受定时和概率限制**，一定执行（动态挑人也会放宽，尽量挑到一个）。
- **验收用 `--test`**：`pnpm agent event <id> --test` 把发送目标强制改成**操作者本人 P2P**（不发到真实目标群/别人），被 @ 的人不在你 P2P 里会自动降级成 `@名字` 文本。可叠加 `--dry-run`。

## 八、奖励/副作用（可选）

- **发 LP**：给谁、多少、什么条件（如【对象曾经 @ 过城邦土地神（有 first_contact）才发】）。
- **发徽章 / 其他**：说明。
- 没有就写【无】。

## 九、其他约束（可选）

- **只发一次 / 每人一次 / 可重复**？
- **什么情况下要跳过不发**？
- 其他你想到的规则。

## 附：一个填好的范例（lurker-discovered）

1. 事件名：🐟 社区潜水被发现了；用途：每周挑一个久未发言的社区成员，@ 出来让大家认识，活跃社区。id：`lurker-discovered`
2. 正文：【今天某个成员的 AI Agent，发现了一个久未发言的社区成员 {{@lurker}}，让我们大家一起来认识他一下吧！】+（对象有 first_contact 才加）【也给他 3 AP 鼓励！】；末尾固定：【此事件固定每周发生一次，发生概率 25%】
3. 配图：https://i.meee.com.tw/6bE3DVH.png ；不叠字
4. 事件来源：SeeDAO 运营小天地 群的成员（+ messages 的最后发言时间）。
5. 通知目标（单一）：SeeDAO 运营小天地 群（生产）。验收用 `--test` 改发操作者本人 P2P（此时潜水者不在 P2P 里，`@` 自动降级成【@名字】文本）。⚠️ 生产发群前要先把 bot 拉进运营小天地。
6. 对象：从来源群（运营小天地）成员里动态挑——最近 3 天没发言（含从没发言过的人），随机一个；**只排除 bot**（操作者/任何人都可被选）；挑不到时手动触发强制挑最久没发言的。
7. 触发：每周礼拜一，时段 19:00-20:00 随机，概率 25%；手动可强制。
8. 奖励：对象**有 first_contact** 才 +3 AP，并在正文加那句；没有则不发也不提。
9. 其他：无特别限制。

## 我拿到后会做什么（你不用管，知道即可）

- 解析群名→chat_id、人名→open_id；下载底图。
- 在 `src/core/events.ts` 用 `registerEvent({...})` 建事件：**来源**逻辑（读名册/messages/DB）放 `prepare(opts)`，**单一目标**用 scope+targetChatId（群）或 `prepare` 返回 `target:{userId}`（P2P）；`prepare` 可返回 `null` 跳过、带 `afterSend` 发奖励。
- 定时的话挂到 supervisor 的日规划器（改 supervisor 需**完整重启 serve**；只改事件定义/文案则 `pnpm agent update` 热重载即可）。DB 状态触发要新增触发钩子（按需做）。
- 给你 `pnpm agent event <id> --dry-run` 先预览（不发送、不发 LP），确认无误再真发。
- 日志一律简体中文无 emoji；注释英文。
