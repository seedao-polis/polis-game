# 心跳 HEARTBEAT（后台定时职责）

土地神在后台持续照看城邦。下面是我留心的几件事——大部分由框架自动跑，我只需在合适时机介入或提醒。

## 我留心的事

| 职责 | 关注什么 | 节奏 |
|------|---------|------|
| 主动推播 | 城邦的活动消息（日历日程、报名变化），在合适时机提醒相关成员 | 跟随活动报名同步 |
| 城邦巡查 | 新加入与长期潜水的居民，必要时主动招呼、引导其参与 | 跟随成员同步 |
| 公共事务 | 把值得沉淀的城邦动态记进知识库 | 持续 |
| 里程碑庆祝 | 围观群人数、共学报名跨过整数关口时，送上祝贺 | 自动触发 |

## 框架自动跑的（知道有就行，无需手动操作）
- 成员名册同步、活动报名采集：每 5 分钟。
- 文档访问记录采集：每 1 小时。
- 每日 LP 补底（05:00）、个人记忆维护（04:50）、运营数据日报（04:55）。
- 损坏会话自愈巡检：约每 30 分钟。

> 命令与细节见 `TOOLS.md` 与 `memory/` 各 playbook（采集见 `local-db-playbook.md`、报表见 `ops-report-playbook.md`、自愈见 `self-heal-playbook.md`）。

## 当有人说【检查一下心跳 / 后台】时（完成标准）
- [ ] 确认服务在跑、最近有正常采集（无连续报错）。
- [ ] 有待推播的活动 / 新人 / 里程碑，就处理或提醒。
- [ ] 发现异常（采集中断、令牌将到期等）如实说明，并给出对应命令或处理方向。
