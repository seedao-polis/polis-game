# 事件规格表（收集需求用）

逐项填好，缺的字段问用户或按默认值处理。群名 / 人名可写中文，落地时解析成 `chat_id` / `open_id`；图给链接或路径，下载存进 assets。不确定的写【不确定】或留空，按默认处理或回头确认。

<basic>
## 一、基本信息（必填）
- **事件名（标题）**：____（可带 emoji；可带占位符，如 `🐟 {{lurker_name}} …`）
- **一句话用途**：____（想达到什么效果、什么时候该发生）
- **事件 id**：____（kebab-case，如 `lurker-discovered`；不填可代起）
</basic>

<content>
## 二、文案（必填）
- **正文**：____（直接写最终文案；变量处用占位符）
  - 时间类：`{{date}}` `{{date_cn}}` `{{time}}` `{{weekday_cn}}`
  - 对象类：`{{name}}` `{{pt}}` `{{level}}` `{{badges}}`
  - @ 某人：`{{@key}}`，并在第六节说明 key 是谁
- **条件句**（可选）：____（【满足某条件才加的句子】，把条件和那句话列清楚）
- **末尾固定说明**（可选）：____（如【每周一次，25% 概率】）
</content>

<image>
## 三、配图（必填其一）
- **底图**：____（图片链接或现有路径；下载存 `workspaces/<soul>/assets/events/<id>/base.png`，全分辨率）
- 发送自动等比缩放到 128px 高；要别的高度就写 ____
- **叠字**（可选）：要的话写 叠什么字 / 大概位置（左中右·上中下）/ 颜色；不要就留空
</image>

<source>
## 四、事件来源（必填）—— 从哪里【看出来】要发生
- **来源群**：____（一个或多个群名，或【全部监听群】）
- **DB 状态**（可选）：____（依赖哪些阈值，如【某人 LP 破某值】【某人升到 N 级】【N 天没发言】）
- 备注：来源 ≠ 目标。来源是素材/触发依据，目标是发给谁。
</source>

<target>
## 五、通知目标（必填）—— 发给谁，只有一个
- **二选一**：发到**一个群**（写群名）____ 或 发**一个人 P2P**（写人名）____
- 一次只发一个目标。被 @ 的对象不在目标会话也没关系（自动降级成 @名字 文本）。
- ⚠️ 目标是群时：bot 必须已在该群，否则发不出（230002）；P2P 无此问题。
</target>

<mentions>
## 六、@ / 对象（针对性事件才填）
- **@/主角是谁**：____
  - 固定某人（写人名）/ **动态挑选**（从第四节来源群成员里按规则挑）
  - 动态规则：范围（来源群成员 / 只发过言的 / 满足某阈值的）、条件（近 N 天没发言 / 从没发言 / 新加入 / 刚升级 / LP 刚破某值）、随机一个还是最符合的一个
- **排除谁**：默认只排除 bot 自己；要额外排除写 ____
- **挑不到人时**：不发 / 还是强制挑一个演示（手动触发默认强制挑一个）
</mentions>

<trigger>
## 七、触发方式（必填）
- **只手动**：写【手动】
- **定时 + 随机**：选周期并给概率（和时段）
  - 每 N 分钟 / 每 X 天 / 每周礼拜几（1=周一…7=周日）/ 每月第几号 / 每年某月某日
  - 时段：本地 `HH:MM-HH:MM`（逻辑日按 05:00→次日 04:59）
  - 概率：____（如 25%）
- **DB 状态触发**（个人 P2P 类）：写明【当某人 <某状态变化> 时 P2P 给他发】
</trigger>

<reward>
## 八、奖励 / 副作用（可选）
- **发 LP**：给谁、多少、什么条件 ____
- **发徽章 / 其他**：____
- 没有就写【无】。
</reward>

<misc>
## 九、其他约束（可选）
- 只发一次 / 每人一次 / 可重复？____
- 什么情况跳过不发？____
- 其他规则：____
</misc>

<example>
## 附：填好的范例（lurker-discovered）
1. 事件名：🐟 社区潜水被发现了；用途：每周挑一个久未发言的成员 @ 出来活跃社区；id：`lurker-discovered`
2. 正文：【发现了一个久未发言的成员 {{@lurker}}，大家来认识一下！】+（对象有互动记录才加）【也给他 3 LP 鼓励！】；末尾：【每周一次，25% 概率】
3. 配图：某图片链接；不叠字
4. 来源：运营群的成员（+ 最后发言时间）
5. 目标：运营群（生产）；验收用 `--test` 改发操作者本人 P2P
6. 对象：从来源群成员里动态挑——近 3 天没发言（含从没发言），随机一个；只排除 bot；挑不到时手动强制挑最久未发言者
7. 触发：每周一 19:00-20:00 随机，概率 25%；手动可强制
8. 奖励：对象**有互动记录**才 +3 LP，并在正文加那句；否则两者都省
9. 其他：无特别限制
</example>
