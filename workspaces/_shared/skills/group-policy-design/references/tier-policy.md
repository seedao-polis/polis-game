# 群组三级分类与保密策略

<overview>
群按运营者手动标记分三级，决定机器人在该群【能说什么、语气如何】。分级只驱动回应（注入一段提示策略），不对记忆做硬闸控。本文是设定群层级与专属提示时的权威参照。
</overview>

<tier_model>
## 三级模型

不依赖 IM 平台的内部群 / 外部群区分，改用运营者手动标的三级：

| 层级 | 受众 | 机器人可说的范围 |
|------|------|------------------|
| `public`（公开群） | 外部观察者与潜在参与者 | 公开信息、公开活动、参与方式；**不可**透露会员群、工作群的内部事务或未公开决策 |
| `member`（会员群） | 正式会员 | 面向会员的事务与活动；**不可**透露工作群的内部运营细节或未公开决策 |
| `work`（工作群） | 核心工作成员 | 内部运营、治理、协作等各类事务，最开放 |

未列入配置的群默认按 `public`（最保守）。
</tier_model>

<secrecy_direction>
## 单向向下保密

保密方向是单向向下的：

- 公开群不可透露会员群与工作群的事
- 会员群不可透露工作群的事
- 工作群最高，可讨论全部

**保密仅体现在回应上**，由该群的层级提示策略约束机器人语气与范围；并非在记忆存取层硬性阻断。
</secrecy_direction>

<builtin_policy>
## 内建分级政策文字（默认，可逐级覆写）

每个层级有一段默认政策文字，会被注入系统提示。运营者可在配置里逐级覆写；不覆写就用下面的内建默认：

**public**
```
你现在所在的是公开群，面向外部观察者与潜在参与者。可以介绍公开信息、公开活动与参与方式；不要透露会员群、工作群的内部事务、未公开决策或成员私人信息。语气友善、简洁、偏公开传播。
```

**member**
```
你现在所在的是会员群，面向正式会员。可以讨论面向会员的事务与活动；但不要透露工作群的内部运营细节或未公开决策。语气亲切、具体。
```

**work**
```
你现在所在的是工作群，面向核心工作成员。可以讨论内部运营、治理、协作等各类事务。
```

> 覆写是逐级的：只覆写 `public` 不影响另外两级的内建默认。
</builtin_policy>

<system_prompt_append>
## 群专属提示（systemPromptAppend）写作原则

每个群可选填一段专属提示，叠加在分级政策**之后**进入系统提示。写它时：

- **不要重复分级政策**：分级政策已自动注入，这段只写【跟同层级其他群不同的规则】。
- **不要重复人格**：人格设定已在智能体自身的 soul 里，这段只写群专属规则。
- **开头点明情境**：【你现在在〈群名〉……】让机器人知道自己在哪。
- **顺序建议**：受众 → 可以讲 → 不可以讲 → 语气。
- **控制长度**：每次该群对话都会带上这段，建议 ≤ 100 字。
- **可留空**：是选填字段，不填就只用分级政策。

示例（一个公开群的专属提示）：
```
你现在在示例公开群，主要面向对社区感兴趣的外部观察者。多介绍参与方式，少谈内部进度；语气轻松、欢迎提问。
```
</system_prompt_append>

<key_concept>
## 关键观念：分级只驱动提示，不硬闸记忆

- 群层级**只**驱动回应的提示策略：告诉机器人此群保密层级、不准讲上级群的事。
- 群层级**不**对个人记忆做硬过滤：`user:` 个人记忆在任何层级的群都会注入。

这是有意的设计取舍：跨人隔离用命名空间硬保证，跨层级保密用提示软约束。
</key_concept>

<known_limitation>
## 已知限制（务必让用户知情）

若一个人在工作群的对话被自动摘要、浓缩进了他的个人记忆（`user:`），那段摘要理论上会在他之后进入的公开群里也被注入提示——因为个人记忆跨群通用。目前**纯靠分级提示策略软性约束**（机器人被告知【公开群别讲工作群的事】），**未做个人记忆按来源层级的硬闸控**。

要硬化的话需要另做：给记忆加一个【来源层级】标记，读取时按当前群层级过滤。在没有硬化之前，设计涉及高密内容时，应提醒用户这条软约束的边界。
</known_limitation>

<defaults>
## 默认与覆写一览

- `defaultTier`：未标群的兜底层级，设为 `public`（最保守）。
- 每群条目：`{ name, tier, systemPromptAppend? }`。
- `tierPolicies`：逐级覆写默认政策文字（选填）。

落点见 `apply-in-code.md`。
</defaults>
