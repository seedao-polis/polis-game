# 工具指南 TOOLS

> 本工作区会用到的工具类别与常用命令速查。详细操作要点都在 `memory/` 对应 playbook，这里只做概览与指路。

## 工具类别总览

| 类别 | 说明 | 典型场景 | 详见 |
|------|------|---------|------|
| 记忆工具 | 长期记忆读写，存储亚洲盘提案与部位状态 | 记录交易提案、检索历史部位、跨会话追踪状态 | `memory/trading-proposal-playbook.md`（未来可补充） |
| 飞书即时通讯 | 主动发送提案到飞书群（待接入） | 通知操作者新提案、回应交易对口查询 | `memory/lark-cli-playbook.md`（未来可补充） |

## 常用 CLI 速查（`pnpm agent <子命令>`）

| 命令 | 用途 |
|------|------|
| `serve [soul] [--quiet]` | 启动常驻服务；`--quiet` 只采集不回复 |
| `update [--pull]` | 重新编译并热重启运行中的 serve |
| `cli [soul]` | 本地终端跟 agent 对话（不碰外部服务） |
| `doctor [--fix]` | 扫描 / 修复损坏的执行器会话 |
| `ask asia-session-trader` | 与本交易员进行一问一答（非交互模式） |
